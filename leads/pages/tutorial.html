¿Qué hace este bot?
Funcionamiento general y flujo de trabajo

Magic Show Bot te permite enviar mensajes personalizados por WhatsApp a múltiples contactos de forma automática. Cada mensaje usa los datos de cada contacto para ser único.

  • 👥
    Cargás tu lista: creás o importás un CSV con nombre, número, tipo y empresa de cada contacto.
  • ✉️
    Redactás el mensaje: escribís un texto con variables como {nombre} que se reemplazan automáticamente.
  • ⚙️
    Generás el script: la app genera un archivo bot-runner.js listo para ejecutar.
  • ▶️
    Ejecutás en terminal: node bot-runner.js abre WhatsApp Web y envía cada mensaje con delay humanizado.
⚠ Advertencia legal: El uso de bots no oficiales puede violar los Términos de Servicio de WhatsApp y resultar en el bloqueo temporal o permanente del número. Usá el bot con responsabilidad y solo con contactos que consintieron recibir mensajes.
2
Cómo cargar contactos
Manualmente o importando un CSV

Tenés dos formas de cargar contactos en la pestaña Contactos:

  • ➕
    Manual: completás el formulario con nombre, número, tipo y empresa, y hacés click en Agregar. Podés agregar tantos como quieras.
  • 📁
    Importar CSV: arrastrás o seleccionás un archivo .csv. La primera fila debe ser el encabezado con las columnas requeridas.

Formato correcto del CSV:

nombre,numero,tipo,empresa María García,5491167867229,cliente, Juan Pérez,5491198765432,cliente_nuevo, Salón Los Robles,5491155443322,salon,Los Robles TechCorp Argentina,5491166778899,empresa,TechCorp Argentina
Reglas del número: debe incluir el código de país sin el signo +, sin espacios ni guiones. Para Argentina: 549 + código de área + número. Ejemplo: 5491167867229

Una vez cargados podés exportar la base como CSV limpio o como Excel (.xls) desde la barra de exportación.

3
Tipos de contacto válidos
Qué significa cada tipo y cuándo usarlo
cliente
Personas que ya contrataron el show anteriormente. El mensaje hace referencia a la relación previa.
cliente_nuevo
Contactos nuevos sin historial previo. El mensaje es de presentación del servicio.
salon
Salones de eventos. El mensaje apunta a una colaboración para futuros eventos del salón.
empresa
Empresas o corporativos. El mensaje es formal y orientado a eventos corporativos.
Tip: Si un contacto tiene un tipo que no está en la lista de válidos, la app lo marcará como error y no se enviará. Revisá la columna Estado en la tabla de contactos.
4
Cómo redactar el mensaje
Editor, preview en tiempo real y cómo guardar
  • ✍️
    Ir a la pestaña Mensaje y escribir el texto en el editor.
  • 🗂
    Usar el machete de variables para insertar variables con un click exactamente donde está el cursor.
  • 👁
    El preview a la derecha muestra cómo quedará el mensaje para cada contacto — podés seleccionar distintos contactos del selector.
  • 💾
    Hacer click en Guardar mensaje antes de ir a Ejecutar. Sin este paso el bot no tiene mensaje para enviar.
⚠ Importante: El botón "Guardar mensaje" es obligatorio. Si cambiás el texto pero no guardás, el bot usará la versión anterior guardada.
5
Variables disponibles
Cómo personalizar el mensaje para cada contacto

Las variables son palabras entre llaves {variable} que se reemplazan automáticamente con los datos de cada contacto al momento de enviar.

VariableColumna CSVEjemplo de valorDescripción
{nombre}nombreMaría GarcíaNombre completo del contacto
{empresa}empresaLos RoblesNombre del salón o empresa
{numero}numero5491167867229Número de WhatsApp
{tipo}tiposalonTipo de contacto

Ejemplo antes de enviar:

Hola {nombre}! 👋 Nos encantaría trabajar con {empresa} en sus próximos eventos 🎩 ¿Estarían interesados en hablar?

→ Resultado para "Salón Los Robles":

Hola Salón Los Robles! 👋 Nos encantaría trabajar con Los Robles en sus próximos eventos 🎩 ¿Estarían interesados en hablar?
Si la variable no existe: por ejemplo {empresa} para un cliente individual sin empresa, el bot deja el texto {empresa} tal cual en el mensaje. Revisá el preview para detectar estos casos antes de enviar.
6
Ejecutar el bot
Cómo correr el bot real en tu computadora
  • ✅
    Verificar que el checklist en Ejecutar muestra todo verde (contactos ✓, mensaje ✓, variables ✓).
  • ⬇️
    Hacer click en Descargar .js para bajar el script bot-runner.js.
  • 📁
    Mover el archivo a la carpeta de tu proyecto donde tenés Node.js y puppeteer instalados.
  • 💻
    Abrir la terminal en esa carpeta y ejecutar:
node bot-runner.js
  • 📱
    WhatsApp Web se abrirá en el navegador. Escaneá el QR con tu teléfono si no tenés sesión activa.
  • 🤖
    El bot empieza a enviar automáticamente, un mensaje por contacto, con delays aleatorios entre cada envío.
Controles en tiempo real (teclado):
P → Pausar / Reanudar envíos
Ctrl + C → Detener y cerrar el navegador limpiamente
7
Delays y tiempos
Por qué son importantes y cómo configurarlos

El bot espera un tiempo aleatorio entre cada mensaje para simular comportamiento humano y reducir el riesgo de bloqueo por parte de WhatsApp.

ParámetroValor recomendadoDescripción
delayMin28sTiempo mínimo de espera entre mensajes
delayMax35sTiempo máximo de espera entre mensajes
loginTimeout120sTiempo para escanear el QR antes de que se cancele
No uses delays menores a 20 segundos. WhatsApp detecta el envío rápido masivo y puede bloquear temporalmente tu número. Con 28–35s tenés un buen balance entre velocidad y seguridad.

Para 100 contactos con delay promedio de 31.5s → aproximadamente 52 minutos de ejecución total.

8
Errores comunes
Diagnóstico y soluciones rápidas
  • ❌
    Número inválido: verificar que tenga el código de país, sin +, sin espacios. Mínimo 10 dígitos. Ejemplo correcto: 5491167867229
  • ❌
    Tipo desconocido: el campo tipo debe ser exactamente uno de: cliente, cliente_nuevo, salon, empresa. Sin mayúsculas, sin tildes.
  • ❌
    WhatsApp no carga / QR roto: cerrá el navegador, borrá la carpeta session/ y volvé a ejecutar el bot.
  • ❌
    No se encontró el cuadro de texto: WhatsApp Web puede haber actualizado sus selectores CSS. Actualizá puppeteer (npm update puppeteer) y generá el script nuevamente.
  • ❌
    Número no encontrado en WhatsApp: el contacto no tiene WhatsApp o el número está mal. El bot lo marca como error y continúa con el siguiente.
  • ❌
    El mensaje no se personaliza: revisá que la variable esté entre llaves exactas {nombre} y que el nombre de la columna en el CSV coincida exactamente.
Consejo: Siempre revisá el checklist en Ejecutar antes de correr el bot. Si algún ítem está en rojo, resuolvelo primero. El preview de Mensaje también es útil para detectar variables rotas.
